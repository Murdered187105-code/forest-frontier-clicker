# Лесной рубеж — RPG-кликер

Браузерная игра на чистом JS без сборки и зависимостей. Описание механик — в `README.md`, работа с git и выкладка — в `CONTRIBUTING.md`. Читай их только если задача этого требует.

## Запуск

Сервер `game` в `.claude/launch.json` (`python dev-server.py`), адрес http://127.0.0.1:8765. Тестов нет — проверка только в браузере.

## Экономия лимита

Пользователь следит за расходом, поэтому:

- Не изучай проект целиком. Эта карта заменяет обзор: сразу ищи нужное через Grep и читай кусок через Read с `offset`/`limit`.
- Не читай целиком `index.html` (337 КБ) и большие `.js`. В `index.html` есть строки до 5 тыс. символов: при поиске ставь `head_limit` или `-o`.
- Не открывай `assets/`: там SVG до 1,8 МБ. Для проверки хватает имени файла.
- Не запускай субагентов без просьбы пользователя.
- Проверяй правки точечно (`read_console_messages`, `javascript_tool`). Один скриншот в конце и только для видимых изменений.

## Данные и генераторы

- Перезаписываются редакторами из игры: `shop-catalog.js`, `hero-tree-data.js`, `power-strike-data.js`.
- Настройки навыка вручную: `precise-cut-data.js`.
- `item-sets.js` создаётся `tools/make_set_items.py`: правь генератор и запускай его, а не результат.
- `assets/effects/power-strike/` создаёт `tools/make_power_strike_fx.py` (Pillow, перекраска текстур Kenney).
- `assets/monster-dungeon-*.svg` создаёт `tools/make_dungeon_bosses.py`.

## Договорённости

- Прогресс игроков лежит в localStorage: старые сохранения должны продолжать работать.
- Каждый навык, который тратит ману в секунду, подключай к `manaBurnFx` из `mana-burn-fx.js`: эффект на панели и перезарядка 5 с после выключения у всех таких навыков одинаковые.
- Новые механики добавляй в README, в раздел «Что есть в игре» или «Структура», если меняется то, что там описано.
