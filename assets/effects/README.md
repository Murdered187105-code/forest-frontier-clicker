# Эффекты Kenney

Все наборы скачаны с официального сайта Kenney. Лицензии CC0 лежат внутри каждого пакета.

| Набор | Основных PNG в каталоге | Источник | Использование |
|---|---:|---|---|
| Particle Pack | 80 | https://kenney.nl/assets/particle-pack | Искры, огонь, частицы |
| Smoke Particles | 77 | https://kenney.nl/assets/smoke-particles | Дым, взрывы, вспышки, облака |
| Light Masks | 152 | https://kenney.nl/assets/light-masks | Сияние, лучи и световые маски |
| Splat Pack | 36 | https://kenney.nl/assets/splat-pack | Брызги и следы попадания |

Всего 345 изображений без дублирования размеров/основных цветовых вариантов. Это текстуры, не 345 готовых анимаций.
Оригинальные ZIP сохранены рядом с распакованными папками. В них есть дополнительные варианты и исходники.
Для Light Masks в каталоге используется `Transparent`; `Default` и `Inverted` оставлены для масок/шейдеров.
Для Splat Pack используется `PNG/Double (512px)`; также есть меньший размер.
`catalog.json` содержит пути всех выбранных текстур, принадлежность к наборам, ссылки на источники и лицензии.

Пакет скачан в проект, установка Python-библиотек не требуется.
Для браузерной игры используйте PNG из `kenney-particle-pack/PNG (Transparent)`.
В архиве также сохранены варианты с чёрным фоном и примеры Unity; примеры Unity в HTML-игру не подключены.

Каталог: http://127.0.0.1:8765/effects-preview.html
Нажатие на карточку показывает простую демонстрационную анимацию. Есть поиск и фильтр по наборам.
Пересоздать каталог: `python tools/build_effects_preview.py`.

Текстуры готовы к использованию через Image/Canvas или HTML-элементы.
Привязка к ударам и навыкам выполняется отдельно в JavaScript игры.
Effekseer не установлен: для этого набора он не требуется.
